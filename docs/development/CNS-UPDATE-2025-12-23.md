## To Add .personal-cns to Workspace

**Manual Method** (Recommended):
1. File → Add Folder to Workspace...
2. Navigate to `~/.personal-cns`
3. Click "Add"

**Result**: You'll see a new workspace folder "CNS Instance (Personal)" with all your:
- Learning entries
- Session contexts
- Configuration files
- Memory systems
