## ✨ Why Alpaca?

**Key Advantages:**
- ✅ **Permanent API Keys** - Never expire!
- ✅ **Simple Authentication** - Just add keys to `.env`
- ✅ **Official Python SDK** - Well-maintained `alpaca-py`
- ✅ **Fractional Shares** - Buy $100 of any stock
- ✅ **Crypto Trading** - BTC, ETH, and more
- ✅ **Great Documentation** - Comprehensive, clear
- ✅ **Built for Algo Trading** - API-first design

**vs Schwab:**
- No OAuth complexity
- No 7-day re-authentication
- Better developer experience
- Cleaner API design

See `/docs/architecture/schwab-vs-alpaca-comparison.md` for full comparison.
