## 💡 Key Insights

### Watchlist Strategy
- Start with one-way sync (f.insight → Alpaca)
- Easier to implement and test
- Two-way sync can be added later if needed
- Prevents accidental data loss

### Table Component Benefits
- Reduce code duplication (6 tables → 1 component)
- Consistent UX across all tables
- Easy to add new features globally
- Better performance with virtual scrolling

### Auto-Refresh Philosophy
- Aggressive during market hours (real-time feel)
- Conservative when market closed (save resources)
- User always has control (toggle + manual refresh)
- Respects Alpaca rate limits (200/min)
