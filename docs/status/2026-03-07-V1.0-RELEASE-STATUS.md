### **Phase 5A: Basic Position Monitor** (Saturday Afternoon - 4 hours)

**Goal:** Monitor open positions, create SELL proposals when stop loss hits

**Tasks:**
1. **Position Evaluator Service** (2 hours)
   - Create `backend/services/position_evaluator.py`
   - For each open position:
     - Check if price < entry_price * 0.95 (stop loss)
     - Check if price > entry_price * 1.10 (profit target)
     - Check if days_held > 14 (max hold time)
   - If trigger hit → Create SELL proposal

2. **Exit Signal Generator** (1 hour)
   - Calculate stop loss: entry * 0.95
   - Calculate profit target: entry * 1.10
   - Max hold time: 14 days
   - Create proposal with reasoning

3. **Background Monitor Job** (30 min)
   - Create `backend/jobs/monitor_positions.py`
   - Run every 5 minutes during market hours
   - Call position_evaluator service
   - Create SELL proposals when needed

4. **Position Status Display** (30 min)
   - Add status to Portfolio screen:
     - ✅ Healthy
     - ⚠️ Warning (near stop loss)
     - 🔴 Alert (stop loss hit)
   - Show stop loss and target prices

**Completion Criteria:**
✅ Monitor runs every 5 minutes automatically  
✅ Detects stop loss breaches  
✅ Creates SELL proposals in queue  
✅ Portfolio shows position health

### **Phase 6: Auto-Execute Logic** (Sunday Morning - 3 hours)

**Goal:** High-confidence proposals execute automatically

**Tasks:**
1. **Auto-Execute Service** (1.5 hours)
   - Create `backend/services/auto_executor.py`
   - Rules:
     - Scanner proposals: Auto-execute if confidence > 85%
     - Exit signals (stop loss): Auto-execute immediately
     - Profit targets: Auto-execute after 1-hour delay (let it run)
   - Respect risk limits (max_position_size, max_concurrent_positions)

2. **Background Auto-Execute Job** (1 hour)
   - Create `backend/jobs/auto_execute.py`
   - Run every 1 minute
   - Check pending transactions where auto_execute=true
   - Execute if confidence threshold met
   - Mark as "AUTO_EXECUTED" in queue

3. **Agent Configuration** (30 min)
   - User settings page:
     - Enable/disable auto-execute
     - Set confidence threshold (75-95%)
     - Max position size ($3000 default)
     - Max concurrent positions (10 default)

**Completion Criteria:**
✅ High-confidence trades execute automatically  
✅ Stop losses execute immediately  
✅ User can enable/disable auto-execute  
✅ User can set confidence threshold

### **Phase 7: Risk Controls & Monitoring** (Sunday Afternoon - 3 hours)

**Goal:** Ensure system doesn't go crazy

**Tasks:**
1. **Risk Limits** (1 hour)
   - Max portfolio exposure: 80% (keep 20% cash)
   - Max position size: 10% of portfolio
   - Max concurrent positions: 10
   - Max daily trades: 20
   - Max loss per day: 2% of portfolio

2. **Circuit Breakers** (1 hour)
   - If 3 consecutive losses → Pause scanner for 1 hour
   - If daily loss > 2% → Stop all new trades
   - If portfolio value < 90% of start → Alert user, require approval

3. **Alert System** (1 hour)
   - Email/SMS on circuit breaker trigger
   - Daily summary report at market close
   - Position alerts (stop loss hit, profit target reached)

**Completion Criteria:**
✅ System respects all risk limits  
✅ Circuit breakers prevent runaway losses  
✅ User gets alerts on important events
