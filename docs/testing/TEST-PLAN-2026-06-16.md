## 9. Paper Trading Month Plan

**Duration**: ~4 weeks (start date + 28 days)  
**Strategy**: Default variant — earnings momentum + technical breakout  
**AI Gate**: ON for paper trading, threshold 70  
**Review cadence**: Check weekly — look at win rate, avg return, drawdown  

**Promote to Live when**:
- Win rate ≥ 55%
- Average return per trade ≥ 1.5%
- Max drawdown ≤ 8%
- At least 10 closed trades to have statistical confidence

**To promote**: Live Trader tab → **"Promote Strategy from Paper"** button → select active paper variant → confirm.
