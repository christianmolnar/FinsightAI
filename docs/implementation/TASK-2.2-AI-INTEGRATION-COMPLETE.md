### 1. AI Client Integration
**File:** `/backend/services/calibration_engine.py`

Added support for both OpenAI and Anthropic:
- OpenAI GPT-4o-mini (fast, cost-effective)
- Anthropic Claude-3-haiku (fallback option)
- Environment variable control: `AI_MODEL_PREFERENCE`
- Graceful degradation to statistical reasoning if no API keys

**Code Added:**
```python
def __init__(self, db: Session):
    # ... existing code ...
    
    # Initialize AI clients
    self.openai_key = os.getenv("OPENAI_API_KEY")
    self.anthropic_key = os.getenv("ANTHROPIC_API_KEY")
    self.ai_preference = os.getenv("AI_MODEL_PREFERENCE", "openai-gpt4")
    
    self.openai_client = OpenAI(api_key=self.openai_key) if self.openai_key else None
    self.anthropic_client = Anthropic(api_key=self.anthropic_key) if self.anthropic_key else None
    
    if not self.openai_client and not self.anthropic_client:
        logger.warning("No AI API keys found - using statistical reasoning only")
```
